OS96 Image Optimizer beta for Windows and macOS.

- Automatic image compression preserves dimensions; resizing is a separate optional step.
- Add images or folders using the buttons, File menu, or drop zone, then click Start.
- Compare results, export batch reports, and control metadata, color profiles, and parallel processing in Settings.

Downloads:

- Windows: run `Setup.exe`, or extract the portable ZIP and keep its folder intact.
- Apple Silicon Mac: choose `macos-arm64.dmg`.
- Intel Mac: choose `macos-x86_64.dmg`.
- On Mac, open the DMG and drag the app to Applications. macOS 13 or newer is required.

This is a beta. Windows builds are unsigned; Mac builds have ad-hoc signatures only and are not notarized by Apple. Operating-system security prompts may appear. If macOS blocks the app, use System Settings > Privacy & Security > Open Anyway after verifying the download.

Every download has a SHA-256 checksum. Matching third-party source archives and bundled license notices are included with this release. The release workflow tests the frozen apps on each architecture and installation/uninstallation on a fresh Windows runner. These checks do not cover every physical device or guarantee invisible compression differences. Keep backups when replacing originals.
